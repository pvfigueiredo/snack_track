# **App Name**: SnackTrack

## Core Features:

- Product Registration: Implement a user interface to register new products, including name, description, and price.
- Touchscreen Sales Interface: Create a touch-friendly sales interface with large, clear icons for each product.
- Product Search: Implement product search functionality, with autocomplete, on the sales screen.

## Style Guidelines:

- Primary color: Use a warm, inviting color like a light orange (#FFB347) to create a welcoming atmosphere.
- Secondary color: Complement the primary color with a neutral grey (#E0E0E0) for backgrounds and text.
- Accent: Use a vibrant green (#4CAF50) for buttons and interactive elements to draw attention.
- Use a grid-based layout for the product registration screen to ensure a clean and organized look.
- Design the sales interface with large, easily tappable icons, ensuring ample spacing between elements for touchscreen usability.
- Utilize clear and recognizable icons for each product category to aid in quick identification.
